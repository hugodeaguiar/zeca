## Como Posso Contribuir?

### Reportando Bugs

Antes de criar um relatório de bug, por favor verifique as *Issues* existentes para garantir que o problema ainda não foi reportado.

Ao abrir uma nova *Issue* de bug, inclua o máximo de informações possível:
* **Título claro e descritivo**.
* **Passos para reproduzir o problema**.
* **Comportamento esperado** vs **Comportamento observado**.
* **Versões relevantes**: Node.js, NPM, sistema operacional e navegador (se aplicável).
* **Logs ou Screenshots** caso ajudem a ilustrar o erro.

### Sugerindo Funcionalidades

Ideias para novas funcionalidades são sempre bem-vindas!

Para sugerir uma melhoria ou nova funcionalidade:
1. Abra uma *Issue* descrevendo detalhadamente a sua proposta.
2. Explique por que essa funcionalidade seria útil e qual problema ela resolve.
3. Se possível, forneça exemplos de como a API ou interface deveria se comportar.

### Enviando Correções ou Novas Features (Pull Requests)

1. Encontre ou abra uma *Issue* referente ao que você pretende trabalhar antes de começar a codificar (assim evitamos trabalho duplicado).
2. Faça um **Fork** do repositório.
3. Crie uma **Branch** para a sua modificação (`git checkout -b feature/minha-funcionalidade` ou `fix/correcao-bug`).
4. Desenvolva as alterações e adicione testes correspondentes se aplicável.
5. Faça o commit das suas alterações seguindo o padrão de commits do projeto.
6. Envie a branch para o seu fork (`git push origin feature/minha-funcionalidade`).
7. Abra um **Pull Request (PR)** para a branch `main` do repositório principal.
